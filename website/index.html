Switch agents. Keep the thread.

ThreadPort keeps your task in the project: decisions, open tasks, test results and Git state. When you move from Claude Code to Codex, the next agent starts where the last one stopped.

npm install -g threadport
  • CLI available on npm
  • VS Code extension coming soon

What the next agent receives

A context pack is plain Markdown built from what the session recorded. Every section names its source, and a token budget keeps it short enough to read. Pick a detail level to see the real output for the same session.

  • Objective, open tasks and current errors first
  • Live Git branch, HEAD and changed files
  • Decisions with their reasons, test results and notes
  • The diff itself in deep and full modes

A handoff in four commands

Run these from the root of the project you want to track. Everything is stored in .threadport/ next to your code.

  1. Start tracking the project

    threadport init

  2. Describe the task

    threadport new "Fix token rotation"
threadport task add "Write a concurrency test"

  3. Work with the first agent

    threadport run claude
threadport check npm test

  4. Hand off to the next one

    threadport switch codex

Prefer it automatic? threadport hook install claude gives the agent the context when it starts and records edited files and a summary when it stops.

It stays on your machine

Sessions live in a local SQLite database inside the project, ignored by Git. Nothing is sent anywhere unless an agent you launch sends it under its own rules.

Secrets are redacted
API keys, GitHub and cloud tokens, JWTs and passwords are replaced before storage and before any handoff.
Paths can be excluded
.env, keys and secrets/** are left out by default. Add your own in .threadportignore.
You can audit before sharing
threadport privacy audit counts what would be redacted or excluded, without printing it.

The same thread, inside VS Code

The extension opens each session as a Markdown document you edit in place. Write the next instruction, press Ctrl + Enter, and ThreadPort starts the agent in a terminal with the current context.
